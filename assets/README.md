# Assets Folder

Ten folder zawiera zasoby aplikacji (ikony, splash screen).

Pliki wymagane przez Expo:
- icon.png - ikona aplikacji (1024x1024px)
- splash.png - ekran startowy
- adaptive-icon.png - ikona adaptacyjna dla Android (1024x1024px)
- favicon.png - favicon dla wersji web

Obecnie możesz użyć domyślnych obrazów lub stworzyć własne.
Aby wygenerować domyślne assety, uruchom:
```
npx expo install expo-asset
```

Możesz też użyć narzędzia online do wygenerowania ikon:
https://www.appicon.co/
